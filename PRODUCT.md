# Covalynce — Product Context

**Register:** product (SaaS application UI)

## Product Purpose

Covalynce is the financial control layer for enterprise AI spend. Teams connect AI providers, see unified spend and attribution, set budgets and alerts, and optionally route LLM traffic through the gateway for governance.

## Users

- **FinOps / finance** — need plain-language spend answers, budgets, reports, no jargon.
- **Engineering leads** — configure providers, gateway keys, policies, agents.
- **Individual contributors** — view their team’s usage; rarely touch admin settings.
- **Executives** — dashboard overview only; minimal clicks.

## Tone

Clear, calm, authoritative. Explain *why* before *how*. No hype. Comparable to Notion help copy and Vercel docs: short sentences, active voice, zero assumed prior knowledge of FinOps or LLM APIs.

## Anti-references

- Dense Swagger-only API docs
- Dashboards that show metrics without labels or tooltips
- Side-stripe alert cards and gradient hero metrics
- Jargon without glossary links (RPM, FinOps, gateway proxy)

## Strategic principles

1. Every screen answers “what is this?” in the first line.
2. Tooltips on every non-obvious label and metric.
3. First visit: guided checklist + contextual tips; dismissible but recoverable from Help.
4. Help Center is the single source of truth; in-app links beat external README.
